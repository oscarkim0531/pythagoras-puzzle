# 피타고라스 정리 퍼즐

EBSMath의 피타고라스 정리 퍼즐에서 영감을 받아 만든 독립적인 웹 퍼즐입니다. 첫 번째 격자 조각 퍼즐을 제외한 아홉 가지 분할 방식을 3×3 목록으로 제공합니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 별도의 빌드나 의존성이 없습니다. 로컬 서버에서 확인하려면 `python3 -m http.server 8000`을 실행하고 `http://localhost:8000`에 접속하세요.

## 플레이

시작하기 → 퍼즐 선택 → 이름 입력 → 색 조각을 아래 5×5 정사각형으로 드래그합니다. 조각은 놓은 위치에 맞춰 90도 단위로 자동 정렬됩니다. 배치한 조각을 누르면 원래 위치로 돌아갑니다. 모든 칸을 채우면 완료 화면이 나타납니다.

HTML에는 화면 구조와 문구, CSS에는 레이아웃과 시각 디자인, JavaScript에는 퍼즐 데이터와 입력·판정 로직을 나누어 두었습니다. 원본 사이트의 코드나 그래픽 파일을 복사하지 않았습니다.
