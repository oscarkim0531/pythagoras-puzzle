# 피타고라스 정리 퍼즐

첨부된 EBSMath 퍼즐 화면 9장의 조각 위치와 윤곽을 벡터로 옮기고, EBSMath가 공개한 장면 데이터의 목표 영역과 스냅 규칙을 반영한 웹 퍼즐입니다. 기존 격자 퍼즐 9개도 유지하며 두 묶음을 각각 3×3 목록으로 제공합니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 별도의 빌드나 의존성이 없습니다. 로컬 서버에서 확인하려면 `python3 -m http.server 8000`을 실행하고 `http://localhost:8000`에 접속하세요.

## 플레이

시작하기 → 퍼즐 선택 → 이름 입력 → 색 조각을 아래 정사각형으로 드래그합니다. 새 다각형 퍼즐은 조각이 목표 정사각형에 가까워지면 맞는 위치와 방향을 미리 보여주고, 놓으면 자동으로 회전해 붙습니다. 배치한 조각을 누르면 원래 위치로 돌아갑니다. 모든 조각을 놓으면 완료 화면이 나타납니다.

HTML에는 화면 구조와 문구, CSS에는 레이아웃과 시각 디자인, `ebs-levels.js`에는 벡터 조각 및 목표 영역 좌표, `script.js`에는 입력·판정 로직을 나누어 두었습니다. 원본 그래픽 파일은 포함하지 않습니다.
